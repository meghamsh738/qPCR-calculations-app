# Review a saved cDNA preparation in qPCR Planner

Save an explicitly reviewed cDNA preparation package. In the Planner's Samples section, open **Import samples from cDNA Calculator** and choose that package. Check the listed ready and excluded rows and verify the qPCR input per reaction. Apply the ready sample list and build a new layout. The Planner carries sample labels and creates fresh occurrence IDs. It picks up no RNA-input equivalents, stock volumes or earlier plan approvals.

The fictional phase-3 cDNA package opened in an isolated browser. All four source rows were shown, and the replace button required confirmation. Only Practice A and B entered the layout and acquired distinct IDs. The renderer was built from a byte-verified copy of the changed Planner sources, and the guarded API ran from the authoritative Next source with a separate test runtime. Type checks, production build and lint passed. Two focused Node tests cover distinct occurrences, unreviewed and changed packages.
